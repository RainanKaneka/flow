# Design do Flow

O usuário determinou o uso de **ui-taste** para questões de design do projeto.
Antes de alterar interfaces, ler `design/ui-taste/SKILL.md`, os playbooks
pertinentes e `DESIGN.md`. Preservar a identidade visual existente em extensões.

A skill foi obtida do catálogo oficial público da Uizze. Não é necessário
conectar o MCP pago para utilizar suas orientações locais. Não afirmar uma
verificação visual sem inspecionar o resultado renderizado.
