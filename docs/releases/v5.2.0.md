# Flow 5.2.0

## Novidades

- Os peixes do aquário agora têm animações de nado com cauda, barbatanas e piscadas, mantendo os pixels nítidos durante o movimento.
- Mover um peixe no aquário deixa de mostrar uma confirmação desnecessária.
- A aba Aparências separa a personalização do aquário da aparência do aplicativo e do perfil.
- A coleção original agora se chama Musgo. Kawaii e Espaço acrescentam, cada uma, uma cor de destaque, um tema claro/escuro e uma moldura de perfil. As peças podem ser combinadas entre coleções.
- Compras e escolhas das novas aparências também são aceitas nas contas sincronizadas. Itens já adquiridos continuam disponíveis.

## Download para Windows

Baixe `Flow_5.2.0_x64-setup.exe` nos arquivos desta release. Feche o Flow antes de executar o instalador. O identificador do aplicativo permanece o mesmo para preservar os dados locais.

## Validação e limites

Os 558 testes automatizados do aplicativo passaram, e a compilação de produção do frontend foi concluída. As regras do Firestore foram validadas, publicadas e conferidas no projeto `flow-rainan-prod`. Os testes de integração do emulador Firestore não rodaram nesta máquina porque Java não está instalado.

O instalador não possui assinatura digital.
